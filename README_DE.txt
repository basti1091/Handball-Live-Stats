HANDBALL LIVE STATS – UPDATE v9

Änderungen:
- Neues Handball-App-Logo für den iPhone-Home-Bildschirm.
- Neues App-Symbol in 180, 192 und 512 Pixeln.
- PWA-Manifest ergänzt/aktualisiert.
- Service-Worker-Cache auf v12 erhöht, damit die neuen Symbole geladen werden.
- Die Spielfunktionen aus Update v8 bleiben unverändert.

Installation über GitHub Pages:
1. ZIP entpacken.
2. Alle Dateien aus diesem Ordner in dein GitHub-Repository hochladen und vorhandene Dateien ersetzen.
3. Änderungen auf main committen.
4. Auf dem iPhone die bisherige App-Verknüpfung vom Home-Bildschirm entfernen.
5. Die veröffentlichte Seite in Safari mit ?v=9 öffnen.
6. In Safari „Teilen“ > „Zum Home-Bildschirm“ wählen und hinzufügen.

Hinweis: Vor dem Update vorhandene Spieldaten vorsichtshalber exportieren. Das Update verändert keine gespeicherten App-Daten absichtlich.
